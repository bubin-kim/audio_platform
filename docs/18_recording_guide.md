# 18. 녹음 가이드 (수집 현장용)

> 상태: **v1.0 (2026-08-06)** — 파일럿 2개(260804_004·005) 실측 기반.
> 대상: 차량 경적음 수집. 다른 도메인은 §5의 방법으로 목표치를 다시 측정한다.
> 왜 필요한가: 전처리·자동검출은 **이미 묻힌 소리를 살리는 사후 수단**이라 한계가
> 뚜렷하다(docs/17 §7). 애초에 잘 녹음하는 것이 데이터 품질을 결정한다.

## 1. 파일럿 실측 — 무엇이 문제였나

| 지표 | 260804_004 | 260804_005 | 목표 |
|---|---|---|---|
| 피크 레벨 | -12.4 dBFS | **-19.9 dBFS** | **-12 ~ -6 dBFS** |
| 배경 바닥 (전대역 p10) | -54.2 | -52.2 | 낮을수록 좋음 |
| 전대역 여유 (p90-바닥) | 21.7 dB | **14.9 dB** | **20 dB 이상** |
| **경적대역 배경 (300–1500Hz p30)** | **-63.8** | -76.5 | **-70 dB 이하** |
| **경적대역 검출 여유** | **8.8 dB** | 22.4 dB | **15 dB 이상** |
| 같은 설정 검출 결과 | **0개** | 16개 | — |

**핵심 발견**: 두 파일의 경적 최대 에너지는 거의 같다(-54.9 vs -54.0dB).
차이는 **배경 소음**이다 — 004는 배경이 12.7dB 더 높아 경적이 묻혔고,
같은 검출 설정에서 **0개**가 잡혔다. 즉 문제는 "경적이 작다"가 아니라
**"배경이 크다"**이다.

## 2. 다음 수집 때 지킬 것 (우선순위 순)

### ① 배경 소음이 작은 시간·장소를 고른다 — 가장 효과 큼
- 차량 통행·환기구·공조기 소리가 적은 시간대 (심야·이른 아침)
- 마이크를 벽·기둥에서 떨어뜨려 반사음 줄이기
- **바람이 있으면 윈드스크린 필수** (저주파 배경을 크게 올린다)

### ② 마이크를 소리원에 가깝게
- 거리가 절반이 되면 신호는 +6dB, 배경은 그대로 → **여유 +6dB**
- 004처럼 배경이 큰 환경일수록 거리 효과가 결정적

### ③ 게인을 올려 피크 -12 ~ -6 dBFS를 맞춘다
- 005는 -19.9dBFS로 **너무 작게** 녹음됐다 (양자화 여유 낭비)
- 단, 클리핑(0dBFS 도달)은 절대 금지 — 되돌릴 수 없다
- 녹음기 미터가 가장 큰 경적에서 -6dBFS 근처를 치도록 맞춘다

### ④ 방향성 마이크를 쓴다 (있다면)
- 무지향 대신 카디오이드 → 뒤쪽 환경음을 6~10dB 억제

## 3. 현장 체크 (첫 파일 1개로 3분 안에)

수집 시작 전 **시험 녹음 1개**를 반드시 진단한다:

```bash
# 프로젝트 루트에서
cd backend && uv run python ../.claude/skills/audio-diagnose/diagnose.py <파일> \
    --threshold-db -40 --min-silence-sec 0.3
```

또는 플랫폼에 업로드 → **원본 파일 섹션 → "배경 제거 (묻힌 소리 찾기)"** 로
스펙트로그램을 본다. 경적이 밝은 점으로 보이면 OK, 안 보이면 §2를 다시 조정한다.

**합격 기준**: 경적대역 검출 여유 **15dB 이상** (아래 §5 방법으로 측정).
005(22.4dB)는 합격, 004(8.8dB)는 불합격 — 004 방식으로 계속 수집하면
**자동 검출이 동작하지 않는다**.

## 4. 녹음 설정 (고정)

| 항목 | 값 | 이유 |
|---|---|---|
| 샘플레이트 | 48kHz | 파일럿과 동일, 경적 대역(300–1500Hz) 충분 |
| 비트 깊이 | 24bit 권장 (16bit 최소) | 게인 실수 여유 |
| 포맷 | WAV (무압축) | 압축은 대역 정보를 훼손 |
| 채널 | 모노 or 스테레오 | 플랫폼이 모노 평균으로 처리 |
| 파일 길이 | 3분 내외 | 파일럿과 동일, 업로드 상한(200MB) 안 |

## 5. 목표치를 다른 도메인에 다시 잡는 법

경적이 아닌 도메인(심음·산업음 등)은 대역이 다르므로 이 문서의 숫자를 그대로
쓰면 안 된다. `audio-diagnose` 스킬로 **대역별 여유 표**를 뽑아
가장 여유가 큰 대역을 고르고, 그 대역에서 15dB 이상을 목표로 삼는다.
(대역별 여유 표 출력은 docs/17 E-M2에서 스킬에 추가 예정.)

## 6. 이미 수집한 파일은?

- **005 계열(여유 20dB 이상)**: 자동 검출 커팅이 정상 동작 → 그대로 사용
- **004 계열(여유 10dB 미만)**: 자동 검출 불가 → 전처리를 강하게 걸어도
  검출 0개. **재녹음을 권장**하되, 버리기 아까우면 사람이 스펙트로그램으로
  찾아 수동 라벨링하는 방법이 남아 있다
